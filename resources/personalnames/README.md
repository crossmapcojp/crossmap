The data in this dir is downloaded from https://github.com/shuheilocale/japanese-personal-name-dataset/tree/main/japanese_personal_name_dataset/dataset
The name data will be used for transliteration of Japanese names into other supported languages, for best effort.

first_name_man-ja-[language code]-missing.csv and other xxx-missing.csv files should be generated for human or AI Agent to fill, then utilized for transliteration enties which was missed by the rule based transliterations.
